# Mimo Bunny TV: video files

Finished videos and cover images for the **Mimo Bunny TV** YouTube channel.
They live here so scheduling tools (Buffer) can download them from a permanent public link.

- `shorts/`: vertical YouTube Shorts (1080×1920, under 60 seconds)
- `covers/`: Shorts cover images (1080×1920)
- `videos/`: full-length videos (1920×1080)

Direct download link for any file:
`https://raw.githubusercontent.com/deepmusic440-dotcom/Mimo-bunny-tv/main/<folder>/<file>`

All animation, voices, music and sound effects were made for this channel.
